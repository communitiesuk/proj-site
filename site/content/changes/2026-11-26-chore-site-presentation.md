Every project site now has the tabs Overview, Guides, Docs, Weeknotes, Latest
updates and Coming next, with web addresses to match. Pages take the MHCLG
colours, with a light and dark mode switch that remembers the reader's
choice. The overview has a card for each section and the latest weeknote.
Latest updates splits into "By week" and "Timeline". Pull requests, issues,
documents and commits mentioned anywhere on the site link to GitHub. Coming
next groups items by theme, oldest first, and readers can ungroup the list,
reverse the order or choose which themes to show. Issue authors can add a
short public summary, which is the only issue text the site shows. The
writing skills now write the weekly weeknote. Version 0.3.0 of the tools
carries all of this once published.
