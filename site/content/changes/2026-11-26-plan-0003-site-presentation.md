The team planned how to build the new layout for every project site: the
renamed tabs and web addresses, the MHCLG colours with light and dark modes,
links back to GitHub on every page, and a Coming next list grouped by theme
and ordered by the date each item was opened. Readers will be able to
ungroup the list, reverse the order, and choose which themes to show. The
plan also updates the writing skills so that they write the weekly weeknote,
and ends with a new release of the tools.
