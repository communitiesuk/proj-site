After trying several versions of a mock-up built from this site's own content,
the team proposed a new layout for every project site. The tabs become
Overview, Guides, Docs, Weeknotes, Latest updates and Coming next, with web
addresses to match, and the overview explains each section instead of pointing
at a "latest summary". Pages take the MHCLG colours, with clearer separation
between sections and a switch between light and dark modes. Anything that comes
from GitHub links back to it, and upcoming work shows a short description only
where one has been written for the site.
